# Watch an Movie

Una aplicación de descubrimiento de películas hecha con React y Vite. Explora títulos populares, filtra por género, busca por título o director y guarda películas en tu lista.

## Empezar

Requisitos: Node.js 18 o superior.

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
npm run preview
```

## Funciones

- Catálogo de películas con póster, valoración y ficha de detalles.
- Búsqueda en tiempo real por título, director o género.
- Filtros por género.
- Lista de películas favoritas.
- Diseño adaptable a móvil y escritorio.

Las imágenes del catálogo se sirven desde TMDB. La aplicación es una demo de frontend y no requiere una clave API.
